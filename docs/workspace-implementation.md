# 新版样本库基础实现

## 入口与运行

- `/demo`：无需登录的独立演示工作区，首次打开初始化 9 份样本、23 条实验记录。
- `/`：登录后的新版正式数据工作区，读取现有 SQLite 数据。
- `/?page=inventory`、`/?page=sampling` 等旧入口保留，继续支持现有完整入库、取样、修改与用户管理流程。
- 登录页新增 Demo 入口；用户菜单可在演示与正式工作区间切换。

正常开发启动沿用 `npm run dev`。仅预览演示页面且无需初始化管理员凭据时，可以运行 `npx next dev -H 127.0.0.1 -p 3000`。生产验证命令为 `npm run build -- --webpack`，然后 `npm run start:next -- -H 127.0.0.1 -p 3000`。

## 本轮实现

- 浅色样本全景界面、顶部导航、样本搜索、类型与项目筛选。
- 基于真实来源关系的实验链路，支持分支选择；未登记的测序仅显示为下一步入口。
- 样本基础信息、实验列表、项目汇总、人工记录监控视图。
- 实验结果完整字段查看、暂存和提交。已提交记录只读。
- 对比 2–6 条同阶段已提交记录，切换基准、仅看差异、保留缺失值、导出 CSV。
- 测序结果按登记单归属，对同一登记单避免重复加入对比；文本数据量不自动做数值运算。
- 对比快照保存、读取；保留当时的实验记录值和基准。
- 人工填写并保存验证方案草稿，固定关联实验记录；可以导出方案 JSON。
- Demo 样本入库、取样登记、结果回填及本地保存；重置前有明确确认弹窗。
- 桌面与窄屏布局；表格和长链路仅在自身区域横向滚动。

## 字体与视觉

采用系统无衬线字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Segoe UI", sans-serif`。macOS 使用系统字体及中文苹方回退，不依赖在线字体。图标使用项目已安装的 Lucide，贴近参考图的细线图标；没有额外装饰性栅格图像资产。

新版样式限定在 `.ws-app` 下，明确隔离旧页面的表单标签、表格最小宽度与输入框焦点样式。

## 数据边界

- Demo 数据保存在当前浏览器的 `sampledb-workspace-demo-v1`，不会写入正式数据库。
- 正式数据读取与实验结果保存继续走服务端鉴权。新增 `/api/workspace` 汇总当前样本和实验关系，并返回 `Cache-Control: no-store`。
- 正式模式的入库和取样按钮进入现有完整登记页面；不会把 Demo 表单规则用于正式实验。
- 对比快照与验证草稿目前保存在当前浏览器，正式模式按用户 ID 区分存储。尚不支持跨设备同步或多人共享。
- 保存实验结果时保留原始未展示字段，避免局部表单清空其他信息。测序登记单保存后同步更新其各文库的展示。
- AI、结构化质控、分析运行与设备控制尚未接入；运行监控展示的是人工登记和提交状态，不是实时设备状态。
- 当前工作区接口一次读取完整关系，适用于现有小规模本机数据。后续大规模接入应增加分页、按根样本加载链路与聚合索引。
- 对比快照固定的是实验记录值；来源页中的样本基本信息仍来自当前样本档案。

## 验证

- `node --test tests/workspace-model.test.cjs`：7 项测试，覆盖 Demo 关系完整性、缺失值、基准差异、单位匹配、派生编号、环路保护、CSV 转义、正式接口映射与登记单归属。
- `npx tsc --noEmit`。
- `npm run build -- --webpack`。
- 浏览器实测：入库、取样、结果暂存/刷新恢复/提交、加入对比、基准切换、差异过滤、保存快照、读取固定快照、创建验证草稿。
- 视觉检查和限制见项目根目录 `design-qa.md`。

生产构建中同时修正了原有 9 个动态 API 路由和样本打印页的参数类型：统一为当前 Next.js 所需的 Promise 参数；没有改动这些接口的业务逻辑。

验证范围：正式接口在未登录时返回 401；本轮没有对正式数据库执行写入测试。CSV 内容生成和转义通过测试，但内置浏览器未返回下载事件，尚未确认文件在操作系统下载目录中的落盘结果。
